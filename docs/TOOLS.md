# 도구 고르기 — 수집은 Playwright, 채우기는 에이전트 브라우저

## 한 줄

> **수백 번 똑같이 읽는 일은 코드에게, 한 건씩 보고 판단하는 일은 에이전트 브라우저에게.**

| | 수집 (밤) | 답글칸 채우기 (아침) |
|---|---|---|
| **맥** | Playwright | ego lite 또는 Aside |
| **윈도우** | Playwright | Aside |

## 두 작업은 성격이 반대다

| | 리뷰 수집 | 답글칸 채우기 |
|---|---|---|
| 한 번에 다루는 양 | 수백 ~ 수천 건 | 1건 |
| 언제 | 매일 정해진 시각, **사람 없이** | 사장님이 누를 때만 |
| 반복성 | 1번째와 300번째가 똑같다 | 리뷰마다 화면이 다르다 |
| 틀리면 | 다시 돌리면 그만 | **손님에게 바로 보인다** |
| 필요한 것 | 정확함 · 공짜 · 창 없이 | 평소 로그인 · 눈으로 확인 |

## 왜 사람처럼 브라우저를 여나

배민 · 쿠팡이츠 · 네이버 모두 **사장님용 공식 리뷰 API 가 없습니다.**
어드민은 자바스크립트로 화면을 그리는 앱이라 주소만 불러오면 빈 껍데기가 옵니다.
그래서 진짜 브라우저를 띄워, **어드민이 스스로 받아오는 리뷰 데이터**를 읽습니다.
화면 글자를 긁는 것보다 훨씬 정확합니다.

## Aside 로 둘 다 하면 안 되나? — 직접 설치해 확인했습니다

2026-09-16 · Aside 1.0.914.1 · Aside CLI 1.26.906.1630 · 맥에서 시험.
Aside 는 **2026-09-14 윈도우 정식 출시**(맥 대비 99% 기능)됐습니다.

| 우리가 쓰는 기능 | Playwright | Aside (REPL) |
|---|---|---|
| 페이지 안에서 코드 실행 | 된다 | 된다 (`page.evaluate`) |
| 로그인 쿠키로 어드민 API 호출 | 된다 | **된다** — 같은 출처 `fetch(credentials:'include')` |
| 요청 가로채기 (`page.route`) | 된다 | **없다** |
| 어드민 쓰기 차단 (`enforceReadOnly`) | 된다 | **안 된다** — 가로채기가 없어서 |
| 창 없이 · 사람 없이 | 된다 | **안 된다** — 브라우저 창이 떠 있어야 하고, 연 탭이 앞으로 온다 |
| Aside 계정 로그인 | — | REPL 은 **로그아웃 상태로도 동작** |
| 실행 비용 | 0 | REPL 은 0 (AI 를 안 쓴다) · `aside "할 일"` 에이전트 모드는 크레딧 소모 |
| 윈도우 | 된다 | 된다 |

그래서

- **수집은 Playwright.** 밤에 사람이 안 보는 동안 도는 작업이라,
  어드민에 아무것도 못 쓰게 막는 장치와 창 없이 도는 능력이 필요합니다.
- **채우기는 에이전트 브라우저.** 사장님이 보는 앞에서, 평소 로그인 그대로, 한 건씩.
  Playwright 는 자기만의 브라우저라 플랫폼마다 또 로그인해야 합니다(세 곳이면 세 번).

비용 · 정확도는 차이가 아닙니다. Aside 도 코드 실행 모드(REPL)면 공짜이고 매번 같습니다.
차이는 **쓰기 차단**과 **창 없이 돌기** 두 가지입니다.

## Aside 쓰는 법

```bash
# 맥 — CLI 설치 (앱은 https://aside.com/download)
curl -fsSL https://releases.aside.com/install.sh | bash

# 붙는지 확인
aside repl "const p = await openTab('https://example.com'); console.log(await p.title())"
```

- CLI 는 **Aside 앱이 켜져 있고 창이 하나 이상 열려 있어야** 붙습니다.
- REPL 은 한 번에 **2분**까지 돕니다. `scripts/fill.ts` 는 95초에 스스로 멈춥니다.
- REPL 에서 쓸 수 있는 것: `openTab` · `closeTab` · `listBrowserTabs` · `attachBrowserTab(targetId)` ·
  `installPageScript` · `snapshot` · `annotatedScreenshot` · `sleep(밀리초)`,
  페이지의 `evaluate` · `goto` · `url` · `mouse` · `keyboard` · `screenshot`
- CLI 로 연 탭은 사이드바의 **Agent Tabs** 묶음에 들어갑니다. 사람이 직접 로그인할 화면은
  맥이면 `open -a Aside "주소"` 로 여는 게 보기 편합니다.
- 로그인 화면을 짧은 시간에 여러 번 열면 "만료된 요청" 이 뜹니다. 한 번 새로 불러오면 됩니다.

## ego lite 쓰는 법 (맥)

- https://lite.ego.app 에서 설치하고 온보딩을 마치면 `ego-browser` 명령이 생깁니다.
- 채울 때마다 새 작업 공간을 씁니다. 사람이 넘겨받은 작업 공간은 명령이 멈추기 때문입니다.

## Playwright 로 채우기도 되나

됩니다. 다만 Playwright 는 자기만의 브라우저라 **플랫폼마다 그 창에서 따로 로그인**해야 하고,
로그인이 풀리면 또 해야 합니다. 에이전트 브라우저를 쓸 수 없을 때의 대안입니다.
